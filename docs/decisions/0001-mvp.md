# 0001 — MVP product decisions

**Date:** 2026-10-30
**Status:** Accepted for implementation (defaults; revisit only with evidence)

These decisions unblock phases 1–5. They are intentionally small and can be
changed later without redesigning the application.

| Decision         | Value                                                                                          |
| ---------------- | ---------------------------------------------------------------------------------------------- |
| Account model    | Laravel Starter Kit Team = Cuenta; one owner can have multiple listings subject to plan limits |
| Team members     | Owner at launch; invitations/staff can be added later                                          |
| Visitor account  | Not required for submitting a rental inquiry                                                   |
| Inquiry behavior | Creates a lead/request; dates are not blocked until the owner accepts                          |
| Availability     | One row per listing/date; absent row means available                                           |
| Free plan        | 1 listing, 5 photos, 0 videos, no customer CRM, no AI posts                                    |
| Paid plan        | 5 listings, 20 photos, 3 videos, customer CRM; price configured in Stripe                      |
| Currency         | MXN                                                                                            |
| Billing owner    | The Team/Cuenta, not the individual user                                                       |
| Payments         | Stripe subscriptions only; no PayPal in MVP                                                    |
| Renter payments  | Not processed; deposits are recorded manually by the owner                                     |
| WhatsApp V1      | Click-to-chat `wa.me` link, no automated API                                                   |
| Map              | Leaflet + OpenStreetMap; geocoding provider configurable/manual fallback                       |
| Search           | Bounding box plus exact radius refinement                                                      |
| Moderation       | Owner publishes complete listings; visitors can report; platform can suspend                   |
| Language         | Spanish UI first, translatable strings                                                         |
| Timezone         | UTC storage; account default `America/Mexico_City`                                             |
| Vertical         | `terrace` for V1 with shared listing fields and small validated `details` JSON                 |

## Deferred decisions

- Exact subscription price and trial length.
- Paid AI social-post provider and limits.
- Automated WhatsApp Business API.
- Manual pre-approval of every listing.
- Advanced staff roles and per-member permissions.
- Multi-vertical field builder.

## Consequence

The first launch is a working terrace marketplace with owner listings, guest
inquiries, manual customer/deposit tracking and Stripe subscriptions. It is not a
plugin platform, a generic marketplace builder or a multi-vertical product yet.
