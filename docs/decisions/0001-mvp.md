# 0001 — MVP product decisions

**Date:** 2026-10-30
**Last reviewed:** 2026-11-06
**Status:** Accepted for implementation (amended 2026-11-06)

These decisions define the MVP (internal phases 0–7). They are intentionally small
and can be changed later without redesigning the application.

| Decision         | Value                                                                                                                                                   |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Account model    | Laravel Starter Kit Team = Cuenta; one owner can have multiple listings subject to plan limits                                                          |
| Team members     | Owner, Admin and Member roles with invitations and member management; per-member granular permissions deferred                                          |
| Visitor account  | Not required for submitting a rental inquiry                                                                                                            |
| Inquiry behavior | Creates a lead/request; dates are not blocked until the owner accepts; new/contacted inquiries expire after the requested end date (configurable grace) |
| Availability     | One row per listing/date; absent row means available                                                                                                    |
| Free plan        | 1 listing, 5 photos, 0 videos, no customer CRM, no AI posts                                                                                             |
| Paid plan        | 5 listings, 20 photos, 3 videos, customer CRM; price configured in Stripe                                                                               |
| Currency         | MXN                                                                                                                                                     |
| Billing owner    | The Team/Cuenta, not the individual user                                                                                                                |
| Payments         | Stripe subscriptions only; no PayPal in MVP                                                                                                             |
| Renter payments  | Not processed; deposits are recorded manually by the owner                                                                                              |
| WhatsApp V1      | Click-to-chat `wa.me` link, no automated API                                                                                                            |
| Map              | Leaflet + OpenStreetMap; NullGeocoder/manual coordinates today; external provider pending                                                               |
| Search           | Bounding box plus exact radius refinement                                                                                                               |
| Moderation       | Owner publishes complete listings; visitors can report; platform can suspend accounts, listings and users                                               |
| Language         | Spanish UI first; `lang/es` validation/auth/passwords                                                                                                   |
| Timezone         | UTC storage; account default `America/Mexico_City`                                                                                                      |
| Vertical         | `terrace` for V1 with shared listing fields and explicit details: tipo de espacio, acceso, estacionamiento y vista                                      |

## Amendments

- **2026-11-06:** team invitations and Owner/Admin/Member roles are implemented;
  only per-member granular permissions remain deferred.
- **2026-11-06:** MySQL 8.4 became the primary database and SQLite the
  legacy/test engine. See `0002-data-platform.md`.
- **2026-11-06:** production operating requirements are tracked in
  `0003-production-operations.md`; remaining open items in `0004-open-decisions.md`.
- **2026-11-06:** Spanish translations were added under `lang/es`.

## Deferred decisions

- Exact subscription price and trial length.
- Paid AI social-post provider and limits.
- Automated WhatsApp Business API.
- Manual pre-approval of every listing.
- Per-member granular permissions (basic roles already exist).
- Multi-vertical field builder.
- External geocoding provider and budget.
- UI for the `details` JSON extension.

## Consequence

The first launch is a working terrace marketplace with owner listings, guest
inquiries, manual customer/deposit tracking and Stripe subscriptions. It is not a
plugin platform, a generic marketplace builder or a multi-vertical product yet.
